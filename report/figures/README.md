Put report figures here, using names such as ecg_training.pdf,
pcg_training.pdf, and fusion_comparison.pdf. PNG also works with pdfLaTeX.

Include them from section files using:

    \includegraphics[width=0.85\linewidth]{ecg_training.pdf}

The main document configures this directory as the graphics path. No figure
is required to compile the initial skeleton. State the run and split in each
caption. Avoid screenshots of notebook tables; write tables in LaTeX.
